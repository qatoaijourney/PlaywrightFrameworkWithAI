# Login Functionality Requirement

## Requirement ID

REQ-LOGIN-001

## Business Requirement

Registered users should be able to log in to the e-commerce application using their email address and password.

## Functional Requirements

1. The Login page should contain:
   - Email field
   - Password field
   - Login button
   - Forgot Password link

2. The user should enter a valid email address and password.

3. After successful login, the user should be redirected to the account dashboard.

4. An error message should be displayed when invalid credentials are entered.

5. The account should be locked after multiple failed login attempts.

6. The user session should expire after a period of inactivity.

## Additional Information

- The password should be masked.
- The application should work on supported browsers.
- The user should be able to use the Enter key to submit the form.
